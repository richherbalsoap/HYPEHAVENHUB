Shiprocket's order API does not issue static API keys — the only valid token comes from logging in with an email + password (create one under Shiprocket Dashboard → Settings → API → "API User"). If this variable contains anything other than a real login-generated JWT, every request will fail with 401 Unauthorized. Recommended: remove SHIPROCKET_API_KEY from your environment and use SHIPROCKET_EMAIL + SHIPROCKET_PASSWORD instead.
